## Baseline rule for executors

A plan's "Planned at local main `<hash>`" records WHEN its Current-state
facts were verified — it is not a requirement that HEAD equal that hash.
Commits that only touch `plans/`, `NOTES.md`, or maintainer-owned docs
do not invalidate a baseline. The binding check is the plan's named
Current-state SIGNATURES (functions, constants, tables, doc clauses the
plan cites): verify each against actual code. STOP only when a cited
fact is actually false — and then report the specific mismatch, not the
hash delta.

### Findings considered and rejected (2026-09-08)

- **"SQLite before 3.42 returns NULL from `julianday()` on microsecond ISO timestamps, so leases never expire"**: rejected. SQLite's date parser has accepted any number of fractional-second digits for many years (`parseHhMmSs` loops over digits), and `+00:00` offsets are supported; no minimum-version assertion is needed.
- **"Runtime retry desynchronizes the legacy reasoning run"**: downgraded, not rejected. The once-only legacy completion is by design and pinned by `tests/reason/test_runtime.py::test_live_attempt_rechecks_snapshot_after_authoring_and_preserves_failed_retry`; publication already joins the link table. The real residue (operator decision count, misnamed guard, dead trigger branch) is plan 035.
- **Cursor tokens are unsigned base64**: not a finding; every selecting parameter is re-read from the request, so a forged cursor only re-windows the caller's own result set.

- **Flow-scan cost in `linked_return` / per-point materialization**: measured and bounded by the plan-031 audit, which explicitly declines to claim linear scaling; nothing to add.
