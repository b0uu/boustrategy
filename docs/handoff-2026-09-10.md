## Host facts that are easy to get wrong

- **Tasks must run in the interactive session with RunLevel Highest.** Under a password or
  batch logon, Codex's Windows sandbox runner times out connecting its runner pipe and the
  agent does nothing. Keep the server signed in; disconnect RDP rather than signing out.
- **Codex is the only agent.** A dedicated identity lives at `C:\Users\Administrator\.codex-boustrategy`
  (`CODEX_HOME`), currently logged in with the maintainer's main ChatGPT account until a
  second account exists. Models come from the gitignored `ops/digester.local.psd1`:
  `gpt-5.6-luna` for digests and broker reads, `gpt-5.6-sol` for reviews and execution.
- **Inside the Codex sandbox, Windows TLS has no credentials.** `curl.exe` and
  `Invoke-WebRequest` fail with `SEC_E_NO_CREDENTIALS`; Python `httpx` works. Media is
  downloaded by `python -m app.x.run media --run <run_id>`.
- **The Robinhood grant exposes several accounts**, including the maintainer's personal
  margin account. Only the fingerprint `f00dfeedcafe0001` is bound and enabled. Prompts and
  `docs/execution/EXECUTOR.md` require fingerprint selection before any broker call.
- **The authoring session has web search but no shell and no filesystem.** All eight strategy
  and prompt documents are inlined into the intake by `assemble_intake`.

- **Plan 038**: `app/broker/session.py` (bounded `codex exec` with the Robinhood MCP and a
  strict output schema), `app/broker/collector.py` (snapshot, preflight, prepare-live),
  `app/broker/executor.py` (one broker session per pending intent, ledger verification,

  which produced no-action reviews with zero tool calls. It now grants and directs web
  research, and `docs/prompts/thesis_chain.md` step 2 carries the method.

  `ValuationObservation`, so equity, cash and allocation publish instead of
  `legacy_snapshot_missing_reporting_facts`.
- **Contract drift checks**: `tests/public/test_contract.py` compares the published API
  against the committed browser fixture and refuses an uncovered route;
  `public-ui/src/contract.check.ts` assigns a generated sample to the UI's declared types so

- **Dashboard redesign**: live-only (paper removed from the UI, still published), reviews
  merged into the decision feed, sticky tabs, retained data instead of blanking on tab
